# SIM AI Assistant

SIM AI Assistant 是一套运行于 Apple Silicon Mac 与 Android 手机的 AI 电话接待软件，配合实体 SIM 卡使用，支持 GPT 在线接待和本地离线接待。

## 功能介绍

| 功能 | 描述 |
| --- | --- |
| 双连接模式 | 支持 USB ADB 有线连接及 Shizuku + Wi-Fi 局域网连接，两种模式独立选择；Shizuku 模式无需 Mac 无线 ADB 配对。 |
| 电话自动接待 | 实时监听来电、接通及挂机状态；语音和音频通道就绪后自动接听，支持手动接听与挂断。 |
| GPT 语音接待 | 通过内置 ChatGPT 官方 Voice 网页建立双向电话语音，支持接待提示词保存与复制。 |
| 本地离线接待 | 使用本地中文语音识别和 macOS 系统语音完成常见来意识别及接待，可独立运行，也可作为 GPT 的备用接待。 |
| 可编辑话术 | 支持本地开场、结束话术及 GPT 接待提示词编辑；本地自动播报内容需审核确认。 |
| 音频路由与恢复 | 双向 16 kHz PCM 语音传输、BlackHole 虚拟声卡路由、音频健康检测及异常恢复。 |
| 静默自动挂机 | 可配置对方静默时间，AI 播报期间暂停静默计时。 |
| 通话录音与转写 | 独立授权后保存双向音频和本地识别文字；不会自动插播录音告知。GPT 模式目前仅转写来电者文字。 |
| 飞书 Webhook | 支持已授权的通话文字推送和失败重试；Android 端支持独立的新短信通知，短信配置通过 USB 或手机端完成。 |
| 独立模型下载 | 本地识别模型按需手动下载、校验与缓存，不将模型权重重复打包进安装包。 |
| 连接与后台维护 | 支持连接检测、USB ADB 自动重连、Shizuku 服务状态检测、Android 监听与后台运行管理。 |
| 安装及诊断 | 支持内置 Companion APK 的安装与升级、音频自检、Mac 日志及经 ADB 获取手机诊断、日志清理和诊断包导出。 |
| 安全连接 | Shizuku Wi-Fi 使用证书指纹验证与 TLS 加密，配对信息保存于 Mac 钥匙串，支持撤销配对。 |

## 运行环境

- Mac：Apple Silicon，macOS 13 或以上；GPT 模式需要 BlackHole 2ch / 16ch 和可用的 ChatGPT Voice 会话。
- Android：电话音频功能面向 Android 13 或以上，需安装 SIM AI Companion 并授予相应权限。
- Shizuku Wi-Fi：手机端启动并授权 Shizuku，Mac 与手机位于同一局域网；手机重启后可能需要重新启动 Shizuku。
- 当前为测试版，Shizuku 双向通话音频、系统后台行为及官方 Voice 兼容性需按实际设备验证；单次 PCM 会话上限为 180 秒。

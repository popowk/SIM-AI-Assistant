# SIM AI Companion

Android 手机端伴侣应用，负责电话状态监听、接听挂断、音频服务和短信通知。

- USB ADB：提供私有回环电话状态与控制接口，兼容 Mac 的音频 Helper。
- Shizuku Wi-Fi：通过已授权的 UserService 提供电话音频与控制，使用 TLS 加密的局域网通信，支持独立配对与撤销。
- 电话监听：前台服务、系统电话状态广播、状态快照及后台恢复。
- 短信通知：在用户授权后，将新收到的短信发送至已配置的飞书机器人。
- 诊断：匿名运行日志、服务状态与电源诊断。

电话音频功能面向 Android 13 或以上，具体支持情况取决于设备系统。签名与升级维护见 [签名说明](../docs/ANDROID_SIGNING_MIGRATION.md)。
